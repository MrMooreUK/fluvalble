# Fluval BLE v0.0.13

v0.0.13 is a hotfix release for regressions identified after the larger v0.0.12
feature release. It restores the standard light entity for affected Plant 3.0
installations and includes the related Home Assistant, Bluetooth, and diagnostic
repairs completed since that release.

## Plant 3.0 and Home Assistant fixes

- Restored the single standard Home Assistant light entity for affected Plant
  3.0 installations on Home Assistant 2026.9. Its five physical channels remain
  translated through that one light entity rather than being exposed as
  separate channel sliders.
- Restored config-entry schema compatibility so installations that previously
  used a version 2 entry are migrated instead of being rejected as a downgrade.
- Kept the existing Home Assistant 2024.1 minimum version while using compatible
  translated action errors.

## Bluetooth and diagnostics

- Tightened automatic discovery to require a FluvalConnect-catalogued light
  product ID, preventing pumps, feeders, gateways, and unrelated BLE devices
  from being offered as Fluval lights. Manual setup remains available.
- Added one **Connection mode** diagnostic showing `Persistent` or the exact
  configured timeout, such as `30 seconds`.
- Signal strength and Last seen remain registered but are disabled in persistent
  mode, where advertisement-derived values can be misleading. Selecting a
  finite timeout restores the same integration-disabled entities and preserves
  their history; entities disabled manually remain disabled.

## Reliability and actions

- Serialized complete per-fixture command transactions so concurrent light,
  effect, schedule, preview, clock, and state operations cannot interleave.
- Stopped active schedule previews before normal light and Mode commands so a
  preview cannot overwrite a newer user command.
- Added Home Assistant device targeting to Fluval actions and safer handling
  when more than one fixture is configured.
- Classified invalid action input separately from Bluetooth or fixture failures
  and translated the resulting Home Assistant error messages.

## Upgrade notes

Update through HACS and follow its restart prompt so Home Assistant loads the
new integration code. Routine Fluval BLE option changes continue to use a
config-entry reload and do not require a Home Assistant Core restart.

Plant 3.0 users affected by missing controls should confirm that the integration
now exposes one light entity and that its colour and brightness controls operate
the fixture. Please report the exact model and downloadable diagnostics if a
problem remains.
