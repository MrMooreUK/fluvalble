# Fluval BLE v0.0.17-1

This is a **prerelease** for testing the schedule-card fixes before the next
stable release. v0.0.16 remains the latest stable version.

## Schedule card fixes

- Fix the card getting stuck in the picker during frontend startup.
- Show recognizable fixture names and areas instead of Bluetooth addresses.
- Fix Automatic times and Professional timepoints on SPP fixtures, including
  the five-channel response shared in issue #133.
- Load cached schedule data when opening the card. Use **Reload** for an
  explicit Bluetooth read, with clear timeout errors if it cannot complete.
- Load correctly after selecting a fixture and clarify that viewing a schedule
  tab does not change the light's operating mode.

Also includes a small fix for missing daylight-saving diagnostic values.

## Installing and checking

In HACS, use the **Fluval Aquarium BLE** redownload/version selector to choose
**v0.0.17-1** from the available prereleases. Restart Home Assistant after
installation, then fully refresh the browser or reopen the Companion app.

Look for **Fluval schedule colours** in the dashboard card picker. Check that
the fixture name, Auto times and channel levels, and stored Pro timepoints
match Fluval Connect. Save only if you intend to change the hardware schedule.

Opening the card does not change the fixture's mode or write a schedule.
Please report results in [issue #133](https://github.com/MrMooreUK/fluvalble/issues/133).

Thanks to [Jules](https://github.com/julesjwoods) for the detailed reports and
captured response used to verify the schedule-data repair.
