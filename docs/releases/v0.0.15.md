# Fluval BLE v0.0.15

v0.0.15 makes everyday local control more reliable, keeps fixture scheduling
where it belongs, and improves the information Home Assistant presents for
classic Fluval lights.

## Reliable local control

- Corrects the APK-defined five-channel layout for product 281, including its
  Red, Blue, Purple, Cold White, and Warm White labels.
- Improves command, reconnect, and config-entry lifecycle handling so controls
  and integration actions remain available when more than one Fluval device is
  configured.
- Keeps Bluetooth diagnostics more trustworthy by preserving the timestamp of a
  cached RSSI value and redacting adapter and proxy identifiers from downloaded
  diagnostics.

## Fixture-owned schedules

- Classic Auto and Professional modes can show an **assumed** on/off state from
  the schedule stored on the fixture and its synchronized clock. This is a
  schedule estimate, not a physical illumination sensor.
- Hardware schedules remain programmed and stored in Fluval Connect. Home
  Assistant retains everyday light controls, exact channel sliders, supported
  native effects, mode selection, manual presets, and schedule readback.

## Upgrade notes

- Restart Home Assistant after HACS installs the update.
- If you previously added a Fluval schedule card or its dashboard resource,
  remove it. Schedule cards, local drafts, previews, and schedule-writing
  actions are no longer part of the integration; schedules already stored on
  the fixture are not changed.
- Remove retired schedule actions from scripts and automations. See the
  [hardware-schedule guide](../hardware-schedules.md) for the current workflow.
