# Fluval BLE v0.0.17

v0.0.17 is the stable release after the v0.0.17 prereleases. It fixes
schedule saves for administrators, keeps Reachable accurate when Bluetooth
advertisements are unchanged, and improves schedule editing and classic BLE
reliability. It also includes the schedule card and Manual restore work from
the prereleases.

## Fixes in this release

- Keep Reachable accurate when Home Assistant does not deliver a new callback
  for an unchanged Bluetooth advertisement. Last seen uses the observed
  advertisement time, not the polling time (#152).
- Fix schedule saves for Home Assistant administrators, which previously
  failed before any fixture I/O. Saves remain admin-only (#154, fixes #153).
- Write only changed Automatic schedule fields on FACEBD and FFF0/SPP, keep
  Professional timepoint colours when a time edit reorders points, and
  assemble complete schedule readback from one explicit read (#150).
- Bound and reset the classic BLE receive buffer, and redact free-form BLE
  errors from downloadable diagnostics (#150).
- Trim APK hashes and decompilation references from the documentation (#149).

## Schedule card and Manual controls

These were first shipped in the v0.0.17 prereleases and are included here:

- Fix the schedule card getting stuck in the picker, and show fixture names
  and areas instead of Bluetooth addresses.
- Fix Automatic times and Professional timepoints on SPP fixtures.
- Save the last confirmed Manual channel settings across reloads and
  restarts, and add a Restore last Manual settings button. Restore only works
  when the fixture is already in Manual mode.

## Upgrade notes

- Restart Home Assistant after HACS installs the update.
- If you already installed a v0.0.17 prerelease, this is the matching stable
  release plus the fixes listed above.
