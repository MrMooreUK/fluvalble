# Fluval BLE v0.0.18

Experimental: local Wi-Fi control for AquaSky 3.0. Not yet tested on real
hardware, please open an issue if anything misbehaves.

v0.0.18 adds optional native local Wi-Fi control for AquaSky 3.0 product 532,
using your local MQTT broker. It is off by default. Existing Bluetooth setups
are unchanged until you choose Local Wi-Fi in Configure, or add a new AquaSky 3
over native local Wi-Fi (#146).

## Experimental local Wi-Fi

- AquaSky 3.0 product 532 only. This is not Wi-Fi support for other Fluval models.
- Provisioning is an explicit setup action in Home Assistant. No vendor cloud
  account is used.
- You can switch an existing entry between Bluetooth and local Wi-Fi without
  replacing entities or Manual settings.
- See the [native Wi-Fi setup guide](../native-local-mqtt.md) for provisioning
  steps, security notes, and the hardware test checklist.

## Upgrade notes

- Restart Home Assistant after HACS installs the update.
- Bluetooth-only installs keep the original setup flow. Nothing changes until
  you opt in.
