# Fluval BLE v0.0.12

v0.0.12 is a major feature and reliability update. It expands fully local
control across supported Fluval fixtures, adds fixture-owned schedules and
effects, improves colour accuracy, and makes Bluetooth communication more
dependable.

## Highlights

- Added local BLE support for **Fluval Plant Pro / Plant 4.0**, including power,
  mode, five-channel colour, live state, clock synchronization, native effects,
  and fixture-owned schedules.
- Expanded **AquaSky 3.0** support with native effects, Auto and Professional
  schedules, schedule previews, daylight-saving control, and firmware reporting.
- Added fixture-native **Auto and Professional scheduling**, timed effect
  windows, schedule readback, previews, and classic P1-P4 presets.
- Improved automatic fixture identification using product information decoded
  from FluvalConnect.
- Reworked colour conversion with FluvalConnect spectrum data for more accurate
  AquaSky, Plant, Marine, and Reef control.
- Added optional persistent Bluetooth connections, faster reconnect recovery,
  and clearer Home Assistant diagnostics.

## Home Assistant improvements

- Added standard downloadable diagnostics with automatic redaction.
- Updated integration reload handling to use Home Assistant's current
  config-entry lifecycle.
- Replaced the temporary **Connection** diagnostic with **Reachable**, which
  better represents whether the fixture can currently be contacted.
- Improved Bluetooth source and signal-strength reporting.
- Failed light, mode, preview, schedule, identify, clock, and daylight-saving
  commands now report the underlying BLE problem instead of silently appearing
  successful.
- Prevented BLE reconnects and integration unloading from racing an in-flight
  command.

## Fixture and entity changes

- Removed the redundant LED power switch; power is controlled through the
  standard light entity.
- Removed the duplicate schedule-mode selector; Manual, Automatic, and
  Professional modes use one fixture mode control.
- Retired obsolete diagnostic entities and command-sending diagnostic buttons.
- Existing stale entities from earlier versions are removed automatically
  during setup.
- Existing schedule field names and saved configuration entries remain
  supported for compatibility.

## Reliability and accuracy fixes

- Corrected classic command framing, checksum handling, channel encoding, state
  parsing, notification reassembly, and command timing to match FluvalConnect.
- Corrected fixture clock weekdays and connection initialization order.
- Corrected supported five-channel manual control and scheduling.
- Corrected native effect catalogues and effect-off reporting.
- Prevented stale fixture responses from immediately replacing a colour just
  selected in Home Assistant.
- Improved Marine and Reef colour translation and AquaSky white-channel
  handling.
- Tightened Bluetooth discovery so unrelated BLE devices are not identified as
  Fluval lights.

## Upgrade notes

After updating through HACS, follow its restart prompt so Home Assistant loads
the new integration code. Routine Fluval BLE option changes use a config-entry
reload and do not require a Core restart. If an included dashboard card still
shows an older interface, refresh the browser to clear its cached frontend
resource.

If a fixture behaves differently after upgrading, include its exact model,
Home Assistant version, downloadable Fluval BLE diagnostics, and relevant logs
in a GitHub issue.

## Technical details

The controller capabilities, product mappings, colour profiles, effects,
schedules, and packet corrections in this release are based on the decompiled
FluvalConnect APK and decoded fixture responses. Plant Pro support also
incorporates the published protocol research and hardware validation from
[@cryystyy's Plant Pro integration](https://github.com/cryystyy/fluval-plant-pro-4-homeassistant).

For the complete implementation history, see the
[v0.0.11...v0.0.12 comparison](https://github.com/MrMooreUK/fluvalble/compare/v0.0.11...v0.0.12)
and the
[technical reference](https://github.com/MrMooreUK/fluvalble/blob/main/docs/technical-reference.md).
