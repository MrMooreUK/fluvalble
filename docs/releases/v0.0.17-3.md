# Fluval BLE v0.0.17-3

Prerelease continuing schedule-card testing. Replaces the withdrawn v0.0.17-2.

## Schedule card

- Day and Night both start collapsed, without a configuration option.
- Remembers which sections you open or close during redraws and tab changes.
- Includes the card-registration, fixture-name and schedule-data fixes from
  v0.0.17-1.

## Channel controls

- Clarifies that device channel sliders show reported Manual values separately
  from Auto/Pro schedule levels. No channel-reporting or light-control behaviour
  has changed.

Please report testing results in [issue #133](https://github.com/MrMooreUK/fluvalble/issues/133).
