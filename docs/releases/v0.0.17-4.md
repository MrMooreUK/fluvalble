# Fluval BLE v0.0.17-4

Prerelease continuing testing of the schedule card and Manual controls.

## Manual controls

- Saves your last confirmed Manual channel settings across reloads and restarts.
- Adds a **Restore last Manual settings** button to recall those settings.
- Restore only works in Manual mode. It never changes the mode, so it refuses
  while the fixture is in Auto or Pro; switch to Manual first.
- Keeps saved settings separate from incoming device reports, so changes made
  outside Home Assistant do not replace them.
- Restoration is explicit: reconnecting or receiving a device update does not
  automatically change the light.

Includes the schedule-card fixes and collapsed Day/Night sections from v0.0.17-3.

Please report testing results in [issue #133](https://github.com/MrMooreUK/fluvalble/issues/133).
