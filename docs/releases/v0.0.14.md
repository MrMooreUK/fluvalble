# Fluval BLE v0.0.14

v0.0.14 packages the channel-control and current-generation fixture work merged
through #104. Exact physical channel sliders return alongside the standard light
entity, optional mode restore after zero, classic manual preset scenes, and
completed Reef / Roma / Shaker / APK-backed transport support.

## Channel controls and scenes

- Restored enabled device-page controls for every physical light channel while
  retaining the standard Home Assistant light entity. Sliders use FluvalConnect
  APK product-specific four- or five-channel names and exact 0–100% values;
  direct channel changes update the light's best-fit display without writing
  the approximate RGB conversion back to the fixture.
- Added an optional per-fixture three-second return to the Auto or Professional
  mode used before exact channel-slider adjustment. Reaching zero still powers
  off immediately; intervening channel, power, or mode actions cancel the
  return. Defaults to off so a stored schedule cannot unexpectedly relight the
  fixture.
- Exposed classic fixtures' four onboard manual presets as device-linked Home
  Assistant scenes (exact P1–P4 channel values). Explicit save remains for
  overwrites.
- Turn the fixture off when every exact physical-channel slider reaches zero.
- Route near-neutral colour-picker white to AquaSky's dedicated Pure White
  emitter, accounting for Home Assistant frontend RGB quantization.

## Current-generation controllers

- Completed Reef 4.0 (546) and Reef Nano 4.0 (547) current-controller handling
  on the shared FFF0/SPP transport.
- Completed Roma & Shaker 2.0 current-controller handling (APK four-channel RGBW
  width and eleven-effect catalogue).
- Reassemble fragmented FFF0/SPP `D2` status reports before decoding so Plant
  PRO, Plant 4.0, and other current controllers return complete state.
- Match FluvalConnect's shared 200 ms command queue and 5 ms chunk interval for
  current-generation BLE controllers.
- Restore a neutral static output after leaving a Reef native effect using its
  APK-defined channel 5 Cold White bank.

## APK capability audit

- Complete an APK-backed capability audit across current and legacy light
  families. Plant channel 4 is labelled Pure White; effect restoration uses
  each product's explicit neutral-emitter metadata. Diagnostics report resolved
  spectrum and product capabilities without changing entity IDs.

## Diagnostics

- Keep the Connected since diagnostic enabled for persistent connections while
  disabling only the stale RSSI sensor. Restored channel controls default to
  enabled.

## Upgrade notes

Update through HACS and follow its restart prompt so Home Assistant loads the
new integration code.

Plant 3.0 users who asked for per-channel sliders (#91) should see exact
physical channel controls alongside the standard light entity after updating to
v0.0.14.
