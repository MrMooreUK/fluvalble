# Fluval BLE v0.0.17-2

Prerelease continuing schedule-card testing.

## Schedule card

- Adds **Start Day and Night collapsed** to the visual card editor.
- Keeps the existing Day-open/Night-closed default when the option is off.
- Preserves section expansion while editing and redrawing the card.

## Channel controls

- Clarifies that device channel sliders show reported Manual values, separately
  from Auto/Pro schedule levels. No channel-reporting or light-control behaviour
  has changed.

Please report testing results in [issue #133](https://github.com/MrMooreUK/fluvalble/issues/133).
