# Security policy

Please report suspected vulnerabilities privately. Do not post credentials,
unredacted diagnostics, or exploit details in public issues.

Use **Security → Report a vulnerability** on this repository when available.
If that option is unavailable, contact the repository owner through a private
contact method listed on their GitHub profile and request a secure reporting
channel before sending sensitive details.

Include the integration and Home Assistant versions, affected component,
reproduction steps, and potential impact. Remove secrets and personal device
identifiers from supporting logs.

Security fixes target the current maintained version. Update to the latest
release before checking whether a reported problem persists.
